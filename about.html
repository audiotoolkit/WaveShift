About the project

Audio tools built for practical workflows.

WaveShift is a browser-based collection of audio conversion tools. The goal is simple: make common file-format tasks easier to understand and complete without asking people to create an account or send recordings to a conversion server.

What the tools do

The converter can create MP3, WAV, FLAC, OGG and M4A output files from supported audio sources. Dedicated pages explain MP3-to-WAV conversion, WAV-to-MP3 conversion and ways to compress WAV recordings. Each page pairs a working tool with practical guidance about file size, codecs, bitrate and quality.

How processing works

WaveShift uses FFmpeg WebAssembly in the visitor's browser. The conversion engine is fetched from a public CDN, and the selected audio is processed locally on the device. This keeps audio files out of a WaveShift conversion server, while still requiring a modern browser with JavaScript and WebAssembly support.

Compatibility and limitations

Audio conversion is resource-intensive. Very large files may use substantial memory or take longer on phones and older computers. Codec support can vary based on the source file and the browser runtime. Keep an original copy of important recordings and verify the output before deleting a source file.

Contact

For feedback or a compatibility issue, use the contact page. Include the source format, browser, device type and a short description of what happened. Do not send private recordings unless you have a secure method and a clear reason to share them.
