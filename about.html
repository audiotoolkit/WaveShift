About the project

Audio tools built for practical workflows.

WaveShift is a set of free audio tools that work in your browser. You can change audio formats without creating an account or sending your recordings to a WaveShift conversion server.

What the tools do

You can convert supported audio files to MP3, WAV, FLAC, OGG and M4A. We also have guides for MP3 to WAV, WAV to MP3 and WAV compression. Each guide explains file size, sound quality and useful settings.

How processing works

WaveShift uses FFmpeg WebAssembly to convert audio in your browser. The conversion engine is downloaded from a public CDN. Your audio file is processed on your device, not uploaded to a WaveShift conversion server. You need a modern browser with JavaScript and WebAssembly support.

Compatibility and limitations

Audio conversion can use a lot of your device memory and processing power. Large files may take longer, especially on phones or older computers. Some audio files may not work if their codec is not supported. Keep your original file and check the converted file before deleting anything.

Contact

Have feedback or a problem with a file? Visit the contact page. Tell us the file format, browser, device and what happened. Do not send private recordings.
